# Agents —— 工作区 Agent 清单与权限边界

> **角色**：登记当前工作区**真正常用 + 显著提效**的 Agent，并强制每个 Agent 明确权限边界。
> **依据**：[`.qoder/constitution.md`](./constitution.md) §6.1、§7。
> **准入门槛（与 skills.md 一致 + 权限边界强制）**：
> 1. 真正好用、确有不可替代的提效点；
> 2. 常用（不是一次性）；
> 3. 在本工作区**成功使用 ≥ 2 次**且每次有可追溯的成功记录；
> 4. 显著提效；
> 5. **必须**配齐《权限边界》六字段：可读 / 可写 / 激活条件 / 禁止行为 / 升级路径 / 复审策略。
>
> **任一字段缺失或权限边界含糊不得入册**。新增 / 移除 Agent 必须同步更新 [`.qoder/README.md`](./README.md) 场景索引与 [`.qoder/constitution.md`](./constitution.md) §6 索引表。

## 跨 Agent 通用红线（**所有 Agent 默认继承，不得在条目中放宽**）

- 不得读取 / 修改 `.env` 系列文件（宪法 §7）。
- 不得跨项目操作；激活项目以外的目录视为越界。
- 涉及 UI 改动必须先读对应 `<project>-design.md`，否则停手（宪法 §7）。
- T0/T1 改动必须经评审闸门，Agent 不得单方面合并（宪法 §2.5）。
- 进度仅以 spec.md / plan.md 状态字段为准，Agent 不得另开进度文件（宪法 §2）。
