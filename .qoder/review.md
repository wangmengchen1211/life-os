# Review —— 踩坑模式库

> **角色**：跨项目复盘资产，记录"已重复发生 ≥ 2 次"的 bug 模式与防御策略。
> **依据**：[`.qoder/constitution.md`](./constitution.md) §2.6。
> **写入门槛**：同一类问题**累计触发 ≥ 2 次**才入册；首次触发**不进入本文件**，仅在对应 plan.md §8 留候选。
> **维护节奏**：每次 §2.6 总结阶段触发；季度 / 半年度审阅时合并、去重、降级或归档。

---

## 条目格式（**所有新增条目必须严格遵循**）

```
### 模式 N：<一句话标题>

- **类别**：<数据库 / 回滚 / 幻觉 / 组件 / 并发 / UI / 配置 / 安全 / ……>
- **复现条件**：<什么场景下会触发>
- **错误模式**：<AI 或人类容易做错的具体行为>
- **防御策略**：<具体写入哪个文件的哪一段，或在 SOP 哪一步强制检查>
- **写入时间**：YYYY-MM-DD（出现第 N 次）
```
