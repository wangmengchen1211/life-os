> **依据**：[`.qoder/constitution.md`](../constitution.md) §2.3、§2.4、§2.5。

## 4. 耦合关系与文件边界（**强制段，缺失即违规**）

### 4.1 白名单（本 Plan 允许修改的文件）

> 必须精确到文件，必要时精确到方法 / 字段。后续 Code 阶段实际改动必须 ⊆ 本表。

- `src/models/order.py`（修改 `status` 字段）
- `src/api/order.py`（新增查询接口 `GET /orders/by-status`）
- `tests/test_order.py`（新增测试用例）

### 4.2 黑名单（依赖但禁止修改的文件）

> 列出本 Plan 会读取 / 引用但**严禁改动**的文件，并说明禁止理由。

- `src/models/user.py` —— 仅做外键引用，绝不修改
- `src/core/payment.py` —— 支付核心模块，T0 资产，禁止任何改动
- `.env` / `.env.*` —— 宪法 §7 铁律，AI 严禁读写

### 4.3 平行 Feature 耦合声明

> 列出与本 Plan 共享模型 / 服务的其他 Plan；任一 Plan 修改共享对象，**必须在两个 Plan 的《风险与回归点》同时登记**。
