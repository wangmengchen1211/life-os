# Skills —— 工作区技能准入清单

> **角色**：登记当前工作区**真正常用 + 显著提效**的技能。
> **依据**：[`.qoder/constitution.md`](./constitution.md) §6.1。
> **准入门槛（缺一不可）**：
> 1. 真正好用、确有不可替代的提效点；
> 2. 常用（不是一次性）；
> 3. 在本工作区**成功使用 ≥ 2 次**且每次有可追溯的成功记录；
> 4. 与同等替代方案相比有**显著提效**（节省时间 / 降低出错率）。
>
> **未达门槛者不得入册**。新增 / 移除技能必须同步更新 [`.qoder/README.md`](./README.md) 场景索引与 [`.qoder/constitution.md`](./constitution.md) §6 索引表。
